# 个人手账 / Personal Daily

[English](README.md) · [简体中文](README.zh-CN.md)

一个用于整理任务、规划想法、安排每日时间、记录感想和处理语音笔记的个人工作区。基于 React、vinext、Cloudflare D1/R2 和 Drizzle，采用 MIT 许可证。

点击页面顶部的 **EN / 中** 切换英文或简体中文。语言选择会在页面跳转和刷新后保留。界面、日历日期和内置示例会随语言切换；你自己添加的任务、笔记和录音内容保持原样。

## 示例内容

任务清单与计划看板使用相同的五个分类：**工作、锻炼、休闲、学习、家务**。

工作示例包括灯塔项目（客户门户）、图谱项目（团队知识库）和青柳项目（产品推广）。学习示例包括金融、Word 文档和政治。十个计划示例中有六个用于工作。

历史记录、日记、日程、录音、转写和活动记录初始为空。日记与历史功能仍可用于记录你自己的日常。本版本不包含跨网站同步。

## 本地运行

需要 Node.js 22.13 或更高版本，以及 npm。

```sh
npm ci
npm run db:setup
npm run dev
```

打开终端显示的本地地址。开发服务器只为回环地址请求提供 `local-dev` 身份，生产版本不会使用这个开发身份。

`db:setup` 会在项目本地创建数据库，并导入 `db/seed.sql` 中的虚构示例。示例使用固定 ID，重复运行不会覆盖你的修改，也不会恢复已移除的示例。若不需要示例，可只执行数据库迁移；任务清单首次打开时会创建五个空分类。

如需语音功能，将 `.env.example` 复制为 `.dev.vars`，填写你自己的 API 密钥。本地开发使用 `SHORTCUT_OWNER_ID=local-dev`。没有 API 密钥时，任务与计划功能仍可使用，语音收件箱会提示尚未连接 AI。

语音处理会把录音发送给配置的 OpenAI 转写模型，并将转写与相关任务背景发送给理解模型。生成的更改需要你审核批准后才会应用。

```sh
npm run build
node --test tests/*.mjs
npm run lint
npx tsc --noEmit --incremental false
```

## 部署

应用依赖 Cloudflare Workers 运行环境、名为 `DB` 的 D1 数据库绑定，以及名为 `BUCKET` 的 R2 存储绑定。`.openai/hosting.json` 只声明绑定，不包含原项目身份。`wrangler.jsonc` 中的资源 ID 是本地占位值；部署时需要创建和配置你自己的资源。

这是一个**单一所有者的个人工作区**。生产环境依赖可信认证网关提供 `oai-authenticated-user-id`，并应将 `SHORTCUT_OWNER_ID` 设置为允许访问的账号 ID。网关必须清除客户端伪造的身份请求头，并阻止用户绕过网关直接访问 Worker。任务和计划数据不是按用户隔离的；使用其他托管方式时，请先接入认证。

对全新的数据库应用 `drizzle/0000_initial.sql`，再执行 `db/seed.sql` 即可加入示例。这是初始数据库结构，不应用来升级原私人项目的数据库。密钥应放在托管平台的运行设置中。语音功能还需要 R2 存储和你自己的 API 密钥。

## 源码结构

- `app/`：界面、API、任务、计划、时间轴和语音处理。
- `app/i18n/`：语言状态、简体中文界面词条与示例翻译。
- `db/schema.ts`：数据库定义；`db/seed.sql`：虚构示例。
- `drizzle/`：全新的初始结构与生成元数据。
- `worker/`：Worker 入口与访问检查。
- `tests/`：任务、计划、语音与双语功能测试。

两种语言使用同一套数据与相同的条目 ID。新增界面词条时，请同时更新 `app/i18n/zh.json`。技术协议名称、JSON 字段和模型名称保持原样。
